# RLS Modules

**Status:** Historisches Brainstorming / Inspirationsmaterial

Dieser Ordner enthält frühe Modulideen aus der Zeit vor der heutigen Abgrenzung zwischen Real Life Stack, Real Life Network Protocol und Real Life Game.

Die Dokumente in diesem Ordner sind aktuell keine Modul-Spezifikation. Sie können hilfreiche Produktideen, User Stories oder UI-Impulse enthalten, aber sie definieren keine verbindlichen RLS-Module und keine fachliche Semantik.

Für neue Modul-Arbeit gilt:

1. RLS-Module sind UI- und Interaktionsbausteine.
2. Module arbeiten gegen Hooks, `DataInterface` und Capability-Interfaces.
3. Module besitzen keine Backend-Annahmen.
4. Module besitzen nicht die soziale Semantik von RLNP.
5. Module besitzen nicht die Spielregeln des Real Life Game.
6. Alte Inhalte in diesem Ordner dürfen als Inspiration genutzt werden, müssen aber frisch gegen die heutige Spec geprüft werden.
